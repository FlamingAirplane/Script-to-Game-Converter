Build and test scripts

Project commands package.json
Every npm run command: build, test, lint and the checks below.
Build settings vite.config.ts
How the website and the single-file offline edition are built.
Offline website scripts/offline-site.ts
Makes the site installable and usable with no connection after one visit.
Offline edition packager scripts/package-single.mjs
Turns the single-file build into the file writers download.
Template compiler scripts/templates.mjs
Turns the Unity and Unreal template files into code the exports use.
App icons scripts/icons.mjs
Draws the icons used when the site is installed.
Social card scripts/og-image.mjs
Draws the picture shown when the site link is shared.
Guide screenshots scripts/guide-screenshots.mjs
Captures the user guide's pictures from the app, so they always match it.
Design publisher scripts/design-publish.ts
Checks a design saved from the admin design editor and makes it the published design.
Adaptation scorer scripts/adapt-eval.ts
Scores the choice suggesters against the evaluation set.
Play excerpts scripts/play-excerpts.mjs
Cuts scenes from public-domain plays into Fountain for the evaluation set.
Unity check scripts/unity-check.ts
Exports the sample stories and runs their tests in a real Unity editor.
Unreal check scripts/unreal-check.ts
Compiles each export's generated Unreal C++ against stand-in headers.
Unreal build scripts/unreal-build.ts
Builds and tests an exported Unreal project with a real Unreal Engine.
Tests tests/
The unit tests, sample scripts, and browser tests for the offline file, offline site, accessibility and layout.

Automation

Pull request checks .github/workflows/ci.yml
Typecheck, tests, both builds and the browser tests in Safari's and Chrome's engines, on every pull request.
Website deploy .github/workflows/pages.yml
Builds this site and the offline edition and publishes them to GitHub Pages.
Release files .github/workflows/release.yml
Attaches the offline edition to each GitHub release.
Unity checks .github/workflows/unity.yml
Runs the Unity export's tests in a real Unity editor.
