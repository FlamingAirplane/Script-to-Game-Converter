About Pen to Ink

Turn a script into a playable story, then hand it to a game developer. A free, open-source tool for writers and game teams: bring in a screenplay or prose, check what was understood, play it, and share it as a web page or hand it to a developer as an Ink story packaged for Unity or Unreal. Everything runs in your browser; your scripts aren't uploaded unless you choose cloud sync.

Questions

Who is it for?

Screenwriters and novelists who want a playable branching story, and narrative designers who want a clean starting point for a game's dialogue.

What is Ink?

Ink is a scripting language for interactive stories, made by inkle and used in many games. Pen to Ink writes Ink for you, so you don't need to learn it, but your developer can edit it directly.

Is my script uploaded anywhere?

No. Converting, playing and exporting all happen on your computer, and your work is kept in this browser. Your writing leaves it only if you choose to move a project through your own private GitHub Gist (with your own GitHub token); a saved project file, or a link holding a small story (which is never sent to this site), are the other ways to move it. The app does ask GitHub two things that contain none of your writing: whether a newer version is out, and the site's current look.

Which files can I import?

Fountain, Final Draft (.fdx), Word (.docx), PDF, Markdown, plain text, Twine and Ink.

Which conversion mode should I choose?

Structured is the one the app recommends, and the best place to start: a script without markers converts scene by scene, and markers you add later, such as @passage or a choice line, plan the branches yourself. Faithful keeps a finished script exactly as written and invents nothing. Interactive adaptation also suggests choices drawn from your text, which you accept or reject.

What does my developer get?

For Unity, a package to add to an existing project (Unity 6, or 2022.3 and later) with the compiled story, a ready-made dialogue UI, voice clips, pictures and a sample scene. For Unreal, a C++ project set up for the Inkpot plugin, with a script that fetches it. Either way, the Ink source is included. It is a story package, not a finished game: the developer adds it to a game and connects it to the gameplay.

Can I make a game without a developer?

You can share a playable web page of the story with anyone. For a visual novel, export a script for Ren'Py, the free engine for dialogue-heavy games: put it in a new Ren'Py project, add pictures and music there, and build it for computers and phones.

Does it cost anything?

No. It's free and open source under the MIT licence.

Can I use it offline?

Yes. After the first visit it works without the internet, and you can install it as an app or download a single-file copy.

Known limits

  • PDF layout is guessed, so check scenes and speakers in Review; a text or Fountain export is more reliable.
  • Italics, bold and underlining are kept (from Fountain, Final Draft, Word, Markdown and Twine). Fonts, dual dialogue and revision marks aren't; the words and structure are.
  • Old Word .doc files can't be read: save them as .docx first.
  • Work is kept per browser. Safari may clear it after a week without a visit unless you add the site to the Dock.
  • Very long scripts work but take a few seconds more; there's no fixed size limit.
  • The Unreal project needs the free Inkpot plugin; its setup script fetches it, which needs the internet once. It is built and tested with Unreal Engine 5.7; on 5.9 the pinned Inkpot release needs a one-line fix (the export's README says which).

Roadmap

  • More import formats and better PDF reading.
  • More export targets, such as Godot.
